# PDF 挖洞簽名工具

手機/平板用的純前端 PDF 簽名工具。所有處理都在瀏覽器裡完成，**PDF 不會上傳到任何伺服器**。

## 流程
1. 上傳 PDF
2. 在頁面上用手指拖出要簽名的框（挖洞），或按「自動偵測欄位」抓表單簽名欄
3. 按「開始簽名」→ 點每個框放大簽名 → 自動等比縮回框內
4. 「下載簽好的 PDF」

## 技術
- `pdf.js` 渲染、`pdf-lib` 套印，單一 `index.html`，無後端。

## 注意
此公開版為**單一裝置**流程（上傳→簽→下載都在同一支手機）。
「傳連結給客戶遠端簽、簽完回傳」需要後端儲存，不在 GitHub Pages 範圍內。
